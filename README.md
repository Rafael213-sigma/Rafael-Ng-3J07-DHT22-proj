# Rafael-Ng-3J07-DHT22-proj
this is a dht22 and arduino esp32 project and this is the git repo
i used a esp32 c3 supermini, a dht22 sensor, 2inch 4spi tft display, tp4056 charging board a 18650 battery and a few buttons plus a buzzer
the esp32 is mainly used for running the program and controlling the dht22 display etc
while the others like the dht22 is used for detecting the humidity and temperature in air, the 2 inch tft display is used for showing different things like the time date and day, the temp or humidity graphs also including a page for checking the battery percentage, 
i also made a website that can sync with the esp32 every 1 sec and shows the graphs and temp and humidity and also the battery percentage and uptime
